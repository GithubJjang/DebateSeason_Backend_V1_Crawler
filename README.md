# 토론철 전용 크롤러

## 1. 배경
: 커뮤니티와 뉴스 정보를 가져오기 위한 목적으로 개발이 되었으며, 이 크롤러는 '오직' 데이터 수집을 위해서만 사용.</br>
(부분적인 장애가 전체 시스템에 전파되는 것을 차단하기 위함. 핵심 키워드 추출기와는 따로 분리된 구조임.)

## 2. 사용된 기술
- JAVA: 팀 차원에서 JAVA로 유지보수하기에 유리함.
- Selenium: 동적 이미지를 가져오기 위함.
- SQLite: 크롤러가 이식될 메모리(4GB)를 고려하면 가장 합리적임.

## 3. 크롤러 작동 원리
### 3-1) 크롤러가 데이터 수집 방법
1. 매번 스케줄링 시간(17시)마다 크롤러가 작동하여 미디어(뉴스, 커뮤니티) 정보를 가져옴
2. 가져온 데이터에서 핵심 데이터(제목, 내용, 작성자 등) 정보를 추출하여 DB에 저장함.</br>
동시에, 현재 진행 중인 상태 정보를 파일 디렉토리에 저장하며, 다음과 같이 작동함.</br></br>

## 4. 재부팅 시, 이전 작업 중단 지점부터 작업 재개를 위한 시스템 설계
- 배경
: 예상치 못한 원인으로 크롤러가 중단된 이후 재부팅 시, 이전 작업부터 재개할 필요가 있음.</br>
따라서, 이전 작업부터 재개하도록 장애 복구 설계를 할 필요가 있음
